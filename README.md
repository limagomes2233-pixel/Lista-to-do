# Lista-to-do
Aplicação web para gerenciamento de tarefas, feita com JavaScript puro e manipulação de DOM — sem frameworks ou bibliotecas externas.

Funcionalidades
Adicionar novas tarefas através de um input
Remover tarefas da lista com um clique
Persistência de dados: as tarefas ficam salvas no localStorage do navegador, então continuam lá mesmo se a página for recarregada ou fechada
Layout responsivo com card centralizado e input + botão organizados lado a lado
Tecnologias
HTML5
CSS3 (Flexbox)
JavaScript (ES6+) — manipulação de DOM, eventos e localStorage
